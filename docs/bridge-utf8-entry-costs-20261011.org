#+TITLE: UTF-8 entry costs, allocation policies and bounded evidence

* Frozen production and scenario scope

Production policy remains the caller-owned encoder qualified at =f48bd8d7=;
the existing PR #18 audit head is =91e4f1e15550740f22d76bfd57ba8ff7bab1c5fc=.
No kernel or SDK installation/build changes are made. These receipts qualify
owner-local bridge transfers, not Org parsing or parallel Scheme execution.
The unavailable intra-VM SMP capability remains a separate failed gate.

An independently retained String and a streaming consumer have different
lifetimes. A consumer that needs every result after the next request cannot
reuse one destination. A consumer that finishes each text before the next
request can retain a scratch buffer instead of allocating every time.
Both paths must freshly encode the current text and validate every byte.

Official =lib/c_intf.c:1254= accepts bounded caller-owned character/byte buffers.
Rust's [[https://doc.rust-lang.org/std/vec/struct.Vec.html#method.clear][Vec::clear contract]] preserves capacity rather than releasing it.
That reuse avoids repeated allocation but retains the largest admitted
buffer. Memory budgets and buffer lifetimes belong to the caller; this audit
does not impose an unmeasured worker-count or request-count threshold.
Returned capacity is not allocator metadata, committed pages or peak RSS.

* Official-source entry algorithm

=lib/_thread.scm:4543-4556= implements =with-exception-catcher= with
=##continuation-capture= and a dynamic exception-handler binding. The existing
raw encoding entry enters that machinery even for successful conversions.
This is a source-level cost hypothesis, not an allocation-profiler receipt.

The status-driver candidate expresses expected type/capacity/scalar failures
as negative fixnums rather than raising/catching exceptions. It uses the
same production C scalar codec, unchanged leaf guards and 256-character
bound, with Scheme polling between leaves and no Scheme body view escaping.
Capacity admission compares length with =capacity / 4=, avoiding an
overflowing four-times-length intermediate. Pointer marshalling remains at
the foreign entry; the candidate is not an unchecked pointer API for Scheme
users. Complete UTF-8 validation remains mandatory before Rust text admission.

Normal error and partial-write contracts must pass independently of timing.
Any measured wall-time regression rejects default promotion. No shrinking,
cached text, changed SDK or relaxed correctness rule substitutes for that
algorithmic qualification.

This is a prototype receipt: baseline mode 5 uses the actual checked ABI,
while candidate mode 9 calls a qualification-only raw status entry. The

Rust ABI framing differs. It is therefore not a qualification of a changed

* Cost and memory balance

GC count/CPU are measured; allocation event counts, bytes allocated by Scheme,
resident memory and allocator relocation are not measured by this receipt.
Source inspection identifies exception machinery and redundant FFI entry as
hypotheses, not complete allocation attribution. The observed GC reduction
does not explain all encoding CPU or wall delay. The host remains non-isolated;
ABBA balances chronology but does not remove external scheduling interference.

The reusable controls retain one logical 13,660-byte scratch destination per
sample on this allocator, rather than producing a separately allocated
13,660-byte String on each request. The per-transfer capacity sum is the same;
it must not be presented as concurrently retained memory. A worker retaining
an unusually large scratch buffer needs a caller-chosen lifecycle/budget,
not mandatory shrinking after every transfer. Independently retained output
can still be compacted when that caller explicitly accepts allocator/copy cost.
No automatic threshold is introduced or admitted by these failed timings.

The next attribution boundary is per-entry allocation/continuation evidence
separate from an uninstrumented matched throughput run. A GC-targeted policy
and a throughput-targeted policy should have explicit resource objectives;
neither may silently replace the frozen default after failing its gate.
