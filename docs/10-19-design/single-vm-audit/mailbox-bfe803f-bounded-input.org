* Source-derived private domain, not a narrowed generic API
Original owned-source admission bounds rate to 1000000 and seconds to 10. The
source ordinal starts at zero, is below rate*seconds, and advances only after
construction/publication. Therefore its maximum is 9999999. With four rows,
the largest intermediate is 17*9999999+31*3=170000076, below even the portable
30-bit fixnum maximum 536870911. All stores are into fresh s64[14], in original
order 0,2,3,...,13; index 1 retains zero. Moduli 16,5,10000 are positive.

A defrules declaration parameter keeps the original generic input factories
unchanged. The existing scheduled path alone selects a new private constructor
with fixnum/not-safe declarations under the above contract. It adds no runtime
predicate, input sharing, FFI hop, queue, actor, lease or source-clock operation.
The generic bignum/type/range behavior, independent oracle, business handler,
per-result capacity return and immediate refill are not replaced. If profile
admission is extended, the arithmetic contract and native edge cases must be
requalified before this private helper can cover the extension.

* Offline timing-boundary audit: no new business run
The frozen diagnostics machine code calls clock_gettime with thread-CPU clock
and the C root counter; it does not enter Scheme. The source's elapsed interval
ends after the drive loop, before percentile scans and stop/join. That interval
is enclosed by the owner CPU snapshots. Rounding CPU upward and adding a
conservative 1000 ns arithmetic margin gives an aggregate owner non-CPU lower
bound of 285927915 ns within the 1239239875 ns source interval. This is a
conditional cumulative bound, not the duration or cause of any single pause.
Both native blocking and runnable waiting remain compatible with these data.
