* Capability-aware copy implementation and three load scenarios

The C copy helper now selects compiler capabilities rather than an OS or SDK
version. With Clang's [[https://clang.llvm.org/docs/LanguageExtensions.html#guaranteed-inlined-copy][guaranteed-inline copy intrinsic]], constant-size blocks
cannot introduce an external function call. GCC uses its constant-size builtin
only with actual canonical module/link qualification. Other compilers retain
the existing byte loop. No kernel, linker policy or optimization flags changed.

Small spans and tails use the byte path; full 64-byte blocks use the builtin.
The block width is a locally measured implementation choice, not a claim about
every CPU's cache line or a workload-count dispatch threshold. Both input fill
and output copy use the same allocation-free helper, with arbitrary byte
alignment and the existing non-overlap contract. Independent owned results
and explicitly caller-owned reused storage remain different safe APIs.

* Scoped-copy audit: reject unsupported allocator and aliasing wins

The installed official ~std/ffi.ss~ supplies ~U8_DATA~ and ~U8_LEN~; official
~std/db/sqlite-driver.ss~ uses a scoped bulk copy into a bytevector. The bridge
already holds the Scheme value inside an allocation-free C section and does
not publish its body pointer. A candidate added local ~__restrict__~ pointers
under the existing non-overlap ABI contract, following the compiler's
[[https://www.gnu.org/software/c-intro-and-ref/manual/html_node/restrict-Pointers.html][restricted-pointer guidance]]. No compiler flags, kernel or linking policy
changed. Canonical regeneration and Release compilation succeeded.

All direct phases below used 40 samples, 25 iterations/sample, one runtime
owner and binary input/output. Measurements are sequential, not randomized;
uncontrolled host activity and different GC histories prohibit causal tail
attribution or a stable throughput claim.

|-------------------+-----------------+------------------+------------------|

The complete-path gain was not demonstrated, so the candidate was removed and

Unlike the owned-result control, its output cannot be retained independently
