* Repair contract

The immutable Gambit SDK still selects its declared compiler. GCC verbose
builds write detailed IRA and reload diagnostics to the exact object-owned
=.ira= and =.reload= paths using =-fdump-rtl-ira-details= and
=-fdump-rtl-reload-details=. The existing monitor reports only new compiler
bytes, with the existing 256 KiB threshold and 100 ms polling interval.
Polling alone emits nothing. All four intermediates (=.i=, =.s=, =.ira= and
=.reload=) are removed before invocation and after success or failure.
Warnings, errors and exit status retain their ordinary diagnostic channels.

Diagnostic selection follows content-verified cache lookup, preserving object
cache identity. Optimizer policy, ABI flags, parallelism and watchdog limits
are unchanged. See [[https://gcc.gnu.org/onlinedocs/gcc-15.2.0/gcc/Developer-Options.html][GCC developer diagnostic options]].
