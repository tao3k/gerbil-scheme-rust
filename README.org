#+title: gerbil-scheme-rust
#+options: toc:nil num:nil

Rust bindings for Gerbil Scheme.

* Scope

=gerbil-scheme-rust= provides a small, explicit boundary between Gerbil
Scheme and Rust:

- raw native bindings and ABI declarations;
- safe Rust wrappers for Gerbil values, modules, and calls;
- build support for Gerbil packages, AOT objects, and native archives.

The repository does not own an application runtime.  Marlin, =poo-flow=,
Deck, policy routing, graph execution, resident agents, and workspace policy
remain downstream concerns.

* Build model

- Cargo owns Rust package metadata and dependency resolution.
- =build.ss= owns Gerbil package compilation.
- Bazel owns cross-language orchestration and the CI target graph.

Both Cargo and Bazel are first-class supported entry points.

* Paired Gambit discovery

Runtime commands and native archive builds share Gambit compiler discovery.
Default selection follows the selected Gerbil executable, including symlinked
Homebrew wrappers with a literal `GERBIL_HOME`, before considering a validated
PATH compiler. Ghostscript's unrelated `gsc` is rejected. Both release versions
and development revision/timestamp version output are recognized. Explicit
`GERBIL_GSC` overrides remain supported and validated by native archive builds.
The selected installation supplies its own native runtime paths; downstream
CI does not need to set a second compiler override.

* Shared build environment

The [[file:.github/actions/setup-gerbil/action.yml][setup-gerbil action]] installs the pinned Gerbil release and its host
prerequisites on Linux and macOS, then exports the paired GSC and build-core
settings. Consumers pin the action to a commit rather than copying the
release installer and GCC setup into their own workflows.

The native-build crate provides =gerbil_command= for compiler-environment
isolation, =resolve_gerbil_executable= for tool lookup, and
=configure_gerbil_runtime_diagnostics= for optional Gambit diagnostics. It
preserves the selected SDK's =GAMBOPT= paths when diagnostics are enabled.
For a shell command that runs before Cargo builds the Rust adapter,
[[file:tools/gerbil-build-command.sh][gerbil-build-command.sh]] provides the same compiler-environment boundary.
