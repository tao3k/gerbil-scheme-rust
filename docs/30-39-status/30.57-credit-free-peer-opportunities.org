* Protocol and ownership

A fresh acquisition asks the shared source for one peer opportunity before
obtaining any active, work or slot permit. Only a claimant with observed free
capacity may donate that opportunity. A capacity-blocked claimant proceeds to
ordinary bounded acquisition without changing opportunity debt. A deferral
retains no request, reservation or credit and therefore causes no capacity-return
publication. It notifies the selected peer and takes the existing owner turn.
The next eligible attempt remains runnable if that peer never executes.

An acquisition that has already queued bypasses the advisory fairness check.
It retains FIFO position and any partially acquired credits until ordinary
completion, cancellation, deadline, close or a differently priced FIFO head.
Fairness never cancels or restarts that acquisition. The actual acquire and final
lifecycle fence still decide admission; availability snapshots grant no rights.
A concurrent head-price change still refunds speculative credits normally.

The peer scan upgrades each eligible wake once and keeps weak producer-lifetime
ownership. This is not a permanent strong reference to a retired producer.
The shared source never moves accepted Scheme values or resumes continuations.
Resource credits still span native root projection; each returned credit is
published before a later arbitrary projector can wait for it.

This refines the existing ProgressFair implementation and owner_lifecycle model;
it introduces no policy, configuration default, polling thread or native ABI.
Short wake ranking and Scheme progress representation are unchanged, allowing
this capture to test the changed candidate without a new parameter matrix.
Scheme owns execution budgets, Actors, green threads, continuations, GC and
exceptions. Rust distributes uncommitted cross-instance messages only.

* Verification boundary

The existing model now requires local claim capacity before donating an
opportunity and explicitly asserts that the staged head owns neither work nor
slot credit after deferral. The required premature-credit-release mutation must
still produce a counterexample. Finite-model safety is separate from native
qualification and does not establish an OS scheduling or arbitrary-owner bound.

Focused unit controls cover exhausted local active capacity without consumed
opportunity debt, bounded fallback when a peer never runs, close eligibility,
and preservation of a pending acquisition's FIFO position. Native tests exercise
the real API through GC, multishot continuation replay, Scheme exceptions,
construction/projection failures, cancellation, timeout and accepted-work drain.
