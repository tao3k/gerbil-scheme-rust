* Historical experiments and negative outcomes

- =profile-control*=, =bounds-control*= and =bounds-minimal*= retain the full
  phase/GC and admission-bound traces. They are diagnostic separate-process
  observations, not paired performance acceptance.
- =candidate*=, =profile-candidate*=, =bounds-candidate*= and =quiet-*= belong
  to the rejected persistent coordinator / standard Gerbil Completion experiment.
  Functional checks passed; latency and throughput did not qualify the change.
- =ab-*= is the eight-process loaded-host block, including compiler interference.
- =final-*= is the small-repair whole-process comparison, retaining its throughput
  and mixed-tail regressions. The later paired experiment narrows attribution;
  it does not erase these outcomes or establish production SLOs.
- =control-actor-batch.ss.txt= freezes the original scheduler.
  =rejected-persistent-actor-batch.ss.txt= preserves the rejected implementation.
- Intermediate compiler failures remain in =build-reuse.log.gz= (extra Scheme
  delimiter) and =build-queue-bounds.log.gz= (trace format argument count).
  They were corrected before the respective native measurements.
- =compiler-surveys.txt= includes only compiler rows from full local inventories.
  Before/after snapshots are not proof of a fully isolated host.

The qualification-only frozen control is installed nowhere as a public runtime.
Both paired arms execute the identical application handler. Four configuration
calls precede each sample in both arms, and can warm its first cohort. Eight
Scheme green workers per VM stay resident across the paired arms. These are
explicit test conditions, not an ordinary production arrival process.

The small runtime repair is retained, but batch CPU p99 is numerically 1.8%
worse, and mixed one-item p99 regresses. Mixed batch tails vary between runs.
There is no all-workload p99 gate pass. Image mappings retain the existing
no-hot-unload contract. No remote CI, release, or zero-leak-for-all-churn claim
is made by these receipts.
