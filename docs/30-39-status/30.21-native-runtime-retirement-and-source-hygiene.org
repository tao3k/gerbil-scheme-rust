#+TITLE: Retire VM-free execution paths and remove generated diagnostics
#+STARTUP: overview

* Runtime direction

Complete Scheme execution stays on fixed owner OS threads. Rust admits and distributes work across native Scheme instances; Scheme retains macros, GC, closures, continuations, Actors and green-thread scheduling. The Gerbil -> Gambit C -> native O2 chain and the ledger's default four-owner configuration remain unchanged.

The working performance baseline remains the latest adopted 10.10x owner-resident payload observation in 30.19. Cleanup is not a runtime optimization, and a different benchmark ratio is not evidence of a cleanup speedup.

* Removed execution paths

- The Scheme-to-Rust IR workspace crate, CLI and code-generation tests.
- The ledger's unused typed-fold producer.
- The VM-free ASCENT Python qualification example, including unpublished staged files.
- The Python support crate's unused transport-only =rust-backend= feature.
- Workspace membership, unused compiler dependencies and the source-inventory assumption that required the retired compiler.

The ledger's own =rust-backend= feature continues to select =instance-backend= and complete Scheme runtimes. There is no compatibility alias or subset fallback for the retired execution paths.

Owned host values and C ABI runtime declarations remain necessary transport/lifetime contracts. A copied host value is not a Scheme VM. The =NO_VM= flag describes that value or an independent C callback; it does not select a Scheme execution backend. Native Scheme calls retain their actual owner VM, roots and thread affinity.

* Source-control cleanup

Removed 944 tracked generated files from the documentation benchmark and diagnostic directories, including raw logs, captures, rejected patches, source snapshots and compressed experiment bundles. The receipt-only Git attributes rule is also removed. The generated directories and documentation log/patch extensions are ignored to prevent accidental re-addition.

The material, including unpublished legacy changes, was copied to a repository-external local archive and independently checked before removal. It is not added to the PR. The current PR file tree contains maintained source, executable tests and English conclusions/reproduction commands. Earlier Git history remains historical; this cleanup does not rewrite it.

Historical reports retain their measured positive/negative conclusions. Links promising generated files in the repository have been removed and their local-diagnostic status made explicit. The rejected scalar projection candidate remains rejected; it is not a public API or production default. No replacement archive or candidate patch is committed.
